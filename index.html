FEATURES_

// Everything SnakeNet can do

⚠️

Early Release: SnakeNet is in active development by daboiyoshi.com. It may be buggy — we're working on it. Thanks for trying it out. Feedback always welcome at info@daboiyoshi.com

Core Browser
🗂️

MULTI-TAB BROWSING

Open unlimited tabs, each with its own independent WebView, live title, and favicon. Chrome-style tab bar with close on hover.

⚡

WEBKIT POWERED

Built on Apple's WebKit engine — the same engine as Safari. Fast, native, and fully integrated with macOS.

🔍

SMART ADDRESS BAR

Type a URL, a search query, or a domain — SnakeNet figures it out. Auto-adds https://, falls back to Brave Search.

🖼️

TAB FAVICONS

Each tab shows the website's favicon pulled in real time. Spinner shown while the page loads.

📊

PROGRESS BAR

A thin accent-colored loading bar shows page load progress across the top of the browser window.

👆

SWIPE GESTURES

Native macOS back and forward swipe gestures via trackpad — just like Safari.

Privacy & Security
🔒

NO TRACKING

SnakeNet collects zero browsing data. No analytics, no telemetry, no phoning home.

🦁

BRAVE SEARCH DEFAULT

Search queries go to Brave Search — an independent engine with no big-tech data collection.

🛡️

macOS SANDBOX

Runs inside Apple's App Sandbox — strictly limited to only outgoing network connections it needs.

Customization
🎨

THEME STUDIO

6 built-in themes: Snake Green, Midnight Blue, Crimson, Purple Night, Solar Light, Clean White. Or build your own with full color pickers.

💾

PERSISTENT THEMES

Your chosen theme is saved across app launches automatically via UserDefaults.

🌙

DARK & LIGHT MODE

Every theme supports dark or light mode. The OS color scheme adapts with your theme choice.

// Who made SnakeNet and why

🐍 What is SnakeNet?

SnakeNet is a macOS web browser built from scratch using Swift and SwiftUI by daboiyoshi.com — the team behind Snake Arcade. It was built as a personal, private, and fully customizable alternative to mainstream browsers, with a focus on simplicity and privacy.

🎮 Snake Arcade & daboiyoshi.com

daboiyoshi.com is the home of Snake Arcade — a games, projects, and IT platform run independently in 2026. SnakeNet is one of our side projects, made available to anyone who wants a lightweight macOS browser they can call their own.

⚠️ Early Release Disclaimer

SnakeNet is an early-stage project. It may be buggy — features might not work perfectly on every machine or macOS version. We're continuously improving it. If you run into issues, please reach out.

  • Some sites may not render perfectly
  • WebKit usage state warnings in the console are harmless
  • Requires macOS 13 Ventura or later
  • Must be built from source in Xcode — no signed installer yet

⚖️ Terms & Privacy

SnakeNet does not collect any user data. No analytics, no crash reports, no telemetry of any kind. For daboiyoshi.com's broader terms, see: ↗ Terms of Service

SnakeNet is early-stage and may be buggy. When reporting an issue, please include:

  • What you were doing when the issue happened
  • A screenshot if possible
  • The URL of the site that caused the problem
